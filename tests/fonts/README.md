# Test fonts

These font files are bundled here only so `tests/run.sh` is self-contained and can register
them with Core Text when it runs the host-side test suite.

- `Figtree-{Regular,Medium,SemiBold,Bold,ExtraBold}.ttf` — [Figtree](https://github.com/erikdkennedy/figtree), licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/).
- `KantumruyPro-{Regular,Medium,SemiBold,Bold}.ttf` — [Kantumruy Pro](https://github.com/danhhong/kantumruy_pro), licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/).

Both families are redistributed here unmodified under the terms of the SIL OFL, which
permits bundling and redistribution as long as the font names are preserved and the license
itself accompanies the files (see the upstream projects for the full license text).
