# react-native-turbo-html

render a html paragraph from  html string

## Installation


```sh
npm install react-native-turbo-html
```


## Usage


```js
import { TurboHtmlView } from "react-native-turbo-html";

// ...

<TurboHtmlView color="tomato" />
```
