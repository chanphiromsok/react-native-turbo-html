How a TurboHtmlView row gets its height before the first frame

Follow one Explore feed row from a React render to pixels. The row's description is a TurboHtmlView; its C++ ShadowNode answers Yoga's size question during layout, so the native view is created at the right height and only draws. Flip the switch to see the same frame when the view can't measure itself.
